# 🏠 Wall Area Calculator Bot

## 📌 О проекте

Telegram-бот для автоматического расчета площади стен помещений при выполнении ремонтных работ.

Проект помогает сократить время подготовки предварительной сметы и уменьшить вероятность ошибок при ручных вычислениях.

---

## 🚀 Возможности

- Расчет площади стен
- Пошаговый ввод параметров помещения
- Проверка корректности введенных данных
- Удобный интерфейс Telegram

---

## 🛠️ Стек технологий

- Python
- aiogram
- Git
- GitHub

---

## 💡 Бизнес-задача

При составлении предварительной сметы мастеру необходимо быстро определить площадь стен.

Бот автоматизирует этот процесс и позволяет получить результат за несколько секунд.
