Telegram Bot for Wall Area Calculation
Описание

Telegram-бот, разработанный на Python с использованием aiogram, предназначен для автоматического расчета площади стен помещения. Проект помогает сократить время подготовки предварительной сметы для ремонтных работ и снизить вероятность ошибок при ручных вычислениях.

Возможности
расчет площади стен;
пошаговый ввод параметров помещения;
удобный интерфейс в Telegram;
обработка некорректного ввода.
